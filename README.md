# Moka Cafe Landing Page

카페 "모카 카페(Moka Cafe)"를 소개하는 심플한 원페이지 랜딩 페이지입니다. 별도의 빌드 도구나 프레임워크 없이 순수 HTML/CSS/JS로 제작되었습니다.

## 폴더 구성

- `index.html` — 페이지 전체 구조
- `style.css` — 전체 스타일 (레이아웃, 색상, 폰트 등)
- `script.js` — 내비게이션 앵커 부드러운 스크롤 처리

## 페이지 섹션

- **Hero** — 카페 슬로건과 메뉴 바로가기 버튼
- **About** — 카페 소개 (원두, 공간, 디저트)
- **Menu** — 음료/디저트 메뉴와 가격
- **Gallery** — 카페 사진 영역
- **Location** — 주소, 영업시간, 연락처

## 실행 방법

별도 설치 없이 `index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.
